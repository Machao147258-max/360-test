## 四、内核驱动面（本轮重点）

### 4.1 自我保护链（用户态 → 内核）

```
SelfProtectAPI2.dll (safemon, "木马防火墙")
   └─ CreateFileW("\\.\360SelfProtection") + DeviceIoControl
        ├── IOCTL 0x22204C   (in 4B / out 4B)  ← 保护状态查询/置位
        ├── IOCTL 0x2D1400   (in 12B / out 0x2800B) → 解析 "\Device\Harddisk*" + "DISKID:" (机器指纹)
        ├── IOCTL 0x170002   (in 0x01010101 / out 8B)
        └─ 服务: 360SelfProtection / HookPort
              └─ 360SelfProtection.sys → hookport.sys → win32k.sys
```

**IOCTL 证据**（`360Safe.exe` Hex-Rays 反编译原文，节选）：

```c
hDevice = CreateFileW(L"\\\\.\\360SelfProtection", 0x80, 3, 0, 3, 0, 0);   // sub_4500F0

// sub_407B70：机器指纹采集（0..15 号物理盘，取 "DISKID:"）
```

### 4.2 关键驱动逐个（附实测导入/字符串证据）

**`safemon/360SelfProtection.sys` / `_win10.sys`**（x86，202,792 B）
- 设备与符号链：`\Device\360SelfProtection`（用户态 `\\.\360SelfProtection`）、`\SystemRoot\system32\drivers\hookport.sys`
- 注册表防护面：`Run`、`Run\360Disabled`、`StartupApproved\Run`、`\Registry\Machine\SYSTEM\CurrentControlSet\Services\{360SelfProtection,HookPort}`、以及 **`SystemCertificates\Disallowed` / `EnterpriseCertificates\Disallowed` / `Policies\...\Disallowed`**（阻止自身证书被拉黑）
- 导入即证据：`PsLookupProcessByProcessId`、`ObOpenObjectByPointer`、`ZwQueryInformationProcess`、`ZwQuerySymbolicLinkObject`、`IoAllocateIrp/IofCallDriver`、`MmSectionObjectType`、52 个 `NtUser*/Zw*` 字符串（被挂钩目标名单）
- 兼容名单里出现 `vmwvscrd.sys`、`win32kbase/full.sys` → 对虚拟化环境与 win32k 分裂有专门分支

**`safemon/hookport_win10.sys`**（HookPort 引擎，83,928 B）
- 155 个 `Nt*/NtGdi*` 目标名：`NtDebugActiveProcess`、`NtCreateThread(Ex)`、`NtQueueApcThread(Ex)`、`NtProtectVirtualMemory`、`NtReadVirtualMemory`、`NtRenameKey`、`NtCreateProfile`，以及 **win32k 图形面 `NtGdiBitBlt/PlgBlt/StretchBlt/TransparentBlt/AlphaBlend/GetPixel/OpenDCW/AddFontResourceW`** → 屏幕抓取、剪贴板/图形类攻击、字体加载（漏洞利用面）监控
- 导入 `KeInsertQueueDpc/KeSetTargetProcessorDpc`（DPC 级 hook）、`ZwMapViewOfSection/ZwUnmapViewOfSection`（宿主进程内联映射）、`MmHighestUserAddress/MmUserProbeAddress`（用户态地址校验）
- 注册表 `Control\Keyboard Layouts` + `KeStallExecutionProcessor` → 键盘/输入相关处理

**`ipc/360hvm64.sys`**（460,056 B，2025-07-14 编译）
- 142 个 `Nt*` 名字表（进程/线程/文件/注册表/内存/节/ALPC/WNF/事务全谱），配合 `MmAllocateContiguousMemorySpecifyCache` + `MmGetPhysicalAddress`（物理内存视角）、`PsSetLoadImageNotifyRoutine`、`ExCreateCallback/ExRegisterCallback`
- 额外导入 `NETIO.SYS`（`NsiRegisterChangeNotification` 等）→ 网络表变更监控；`.data` 段 629 KB（存放规则表）
- 与 `\Device\360SelfProtection`、`IoBuildDeviceIoControlRequest` 共存 → 该模块是**内核拦截 + 转发中枢**的候选，而不是纯虚拟化层

**`SoftMgr/360qpesv64.sys`**（346,824 B）

- 自带**第三方安全驱动名单**：`KISKNL.SYS`、`KSAPI64.SYS`、`QMUDISK64.SYS`、`ZhuDongFangYu`、`SLBDriver`、`tcpip.sys`、`360AntiHacker64`、`DSArk64`、`BAPIDRV64`、`360netmon` 等 → 用于共存/冲突处理
- 机器指纹键 `SOFTWARE\360MachineSignature`

**`deepscan/360fsflt.sys` / `360FsFlt_win10.sys`**（文件过滤，全套最大 600 KB，v53.0.0.31，2026-07 编译）
**`deepscan/{qutmdrv, DsArk, BAPIDRV, AtS}.sys`**、**`ipc/{360AntiHacker, 360Box, 360Camera, qutmipc}.sys`**、**`netmon/netdrv/{50,60,wfp,x64}/360netmon_*.sys`**、**`netmon/360sensordrv/360Sensor*.sys`**、**`antiarp/360LanProtect*.sys`**、**`safemon/{360AntiExploit, 360AntiHijack, 360AntiSteal, 360disproc}*.sys`**、**`SoftMgr/{360elam, 360qpesv}.sys`**、**`EfiMon.sys`**（总计 66 个）
