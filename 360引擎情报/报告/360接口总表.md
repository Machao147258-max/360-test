## 七、`\\.\360SelfProtection` IOCTL 码表（已逆，METHOD_BUFFERED）

`Options`=InputBufferLength，`Read.Length`=OutputBufferLength；返回码：长度不符 `0xC000000D`、未受信进程发非白名单码 `0xC0000022`、未知码 `0xC0000010`、缓冲太小 `0xC0000023`。

| 码 | 语义 | 长度约束 |
|---|---|---|
| 0x222000/004/008/00C/010 | 功能位与子表操作 | `== 4` |
| 0x222014 | 只读常量（返回 **1005**） | `Read.Length == 4` |
| **0x222020** | **自保护总开关**（160 项，**10 项不可关**：69/13/30/14/15/68/29/34/35/11） | `== 4` |
| 0x222024 / 0x222044 / 0x222080 | 按文件名注册保护（`wcsnicmp` 比 `360sdu.dat`/`boxu.dat`） | **只校验 `!= 0`**（⚠️ `wcslen` 越界面） |
| 0x222034/050/054/0A0/0A4 | 置/清内部标志 | 无输入 |
| 0x222038 | 注册进程 + `sub_116D8(pid,-16)` | `!= 0` |
| 0x22203C | `sub_1187E(4B值)` | `== 4` |
| 0x222040 | **进程信任表增删**（表上限 0xFE） | `== 4` |
| **0x22204C** ★无条件放行 | **PID 信任查询**（原地回写 0/1） | `==4` in/out |
| 0x222084/08C | 读 4B 进全局 | `>= 4` |
| **0x222094** | 提交 **0x50 字节结构** | `>= 0x50` |
| 0x222098 | 读 4B → `dword_32F50` | `>= 4` |
| **0x22209C** ★无条件放行 | 探测自保护是否开启 | 无 |
| 0x2220A8 | `ExAllocatePoolWithTag(len)` + 拷贝 | `!=0 && <=0xFFFF` |
| **0x2220AC** ★无条件放行 | 读全局 → 回写 out | `Read.Length >= 4` |

★ 三个无条件放行码（0x22204C/09C/0AC）不受"调用进程受信"门限制。

## 八、分析过程中的自我披露

`解包\360payload\` 里出现了 **`.i64` 文件**（如 `safemon/360SelfProtection.sys.i64`、`hookport_win10.sys.i64`）——那是**我给 IDA 分析生成的数据库**，不是原始载荷内容。**该解包树已被分析动作污染，不再是纯净样本**；如需纯净副本，用 `解包\payload.7z` 或归档的 `jk_payload.7z` 重新解一次。
